# GrainGuard prototype

## Fastest way to run
1. Create a new Python app in Replit (or use a laptop with Python installed).
2. Add `app.py` and `requirements.txt` from this folder.
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
5. For deployment, use Streamlit Community Cloud and select `app.py` as the entry point.

The risk thresholds are illustrative demo rules, not validated agronomic predictions. Weather API access requires internet. Demo mode provides simulated weather if live lookup fails.
